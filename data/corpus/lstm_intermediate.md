# Long Short-Term Memory

Long Short-Term Memory, or LSTM, is a type of recurrent neural network designed to handle long-term dependencies in sequential data[cite: 2].

LSTMs use gating mechanisms to control information flow[cite: 2]. The main gates are the input gate, forget gate, and output gate[cite: 2].

The forget gate decides what information should be removed from the cell state[cite: 2]. The input gate decides what new information should be stored[cite: 2]. The output gate controls what information is passed to the next hidden state[cite: 2].
